# Security Policy

## Supported versions
Only the latest code on the default branch is currently maintained. No release-based support schedule has been established.

## Reporting a vulnerability
Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. If that feature is unavailable, contact the repository owner privately through GitHub.

Include:
- A concise description and potential impact.
- Reproduction steps or a minimal proof of concept.
- Affected commit, branch, or component.
- Any suggested mitigation.

Do not include real credentials, private documents, or other users' data in a report.

## Scope and limitations
This project is a portfolio-stage application. A successful CI run does not constitute a security audit or production-readiness assessment. Do not submit sensitive or confidential data to an untrusted deployment.
