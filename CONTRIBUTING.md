# Contributing

Thanks for considering a contribution.

## Development workflow
1. Fork the repository and create a focused branch.
2. Install the dependencies using the commands in the README.
3. Make the smallest change that addresses the issue.
4. Add or update tests for changed behavior.
5. Run the project's lint, test, and build checks before opening a pull request.

## Pull requests
- Explain the problem and the proposed solution.
- Link related issues when applicable.
- Include screenshots for user-interface changes.
- Document security, privacy, or data-format implications.
- Do not commit credentials, API keys, personal data, generated build output, or local environment files.

## Reporting issues
Include reproducible steps, expected behavior, actual behavior, and relevant sanitized logs. Never include secrets or real personal documents.
